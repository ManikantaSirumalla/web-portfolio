iOS fitness and workout tracking app with plans, nutrition, history, and profile. Built with SwiftUI and SwiftData.

## What's New in 2.0

- **Trainer document import:** Import workout plans from PDF, DOCX, CSV, and spreadsheet files, extract structured data, review exercise matches, and save them as reusable templates.
- **Expanded template system:** Default templates now load from bundled JSON, with category-based browsing, a new detail experience, and centralized weekly/monthly schedule logic.
- **Deeper analytics:** Dashboard now has richer personal-record tracking and muscle-distribution visuals, while workout history adds smarter comparisons, workout quality scoring, and PR detection.
- **Broader reliability coverage:** New automated tests cover exercise matching, template scheduling, performance analytics, personal-record calculations, and workout schedule safety.
- **Cross-app polish:** Profile flows, iCloud backup, widgets/live activities, haptics, and workout visuals were refreshed as part of the 2.0 update.

## Programs (Plan) Tab

**Purpose:** Create and manage fitness programs (workout + nutrition). When no plan exists, a welcome/onboarding view is shown; when a plan exists, three segments: **Overview**, **Workout Plan**, **Nutrition Plan**.

| Feature | Description |
|---------|-------------|
| **Plan creation flow** | Steps: goal, duration, workouts/week, time, diet, etc. |
| **Trainer document import** | Import a trainer-provided workout file and convert it into reusable templates |
| **AI plan generation** | Workout + nutrition plans generated by an LLM |
| **Pattern-based plan generation** | Chunked AI + quality curation + fallbacks |
| **Fallback plan generation** | Rule-based workouts/nutrition when the AI path is unavailable |
| **Overview** | Plan summary, stats, progress |
| **Workout plan** | List of workout days; day detail (exercises, warmup/cooldown) |
| **Nutrition plan** | Nutrition days, meals, macros; day selector |
| **Plan history** | Past plans / history view |
| **Health sources sheet** | Links/sources for fitness & nutrition info |

## Technical notes

- **Stack:** SwiftUI, SwiftData, Charts, Combine; dark theme.
- **Data:** SwiftData with optional iCloud backup; HealthKit for health/recovery where used.
- **Plan generation:** `PlanManagementService` + `PatternBasedPlanGeneratorService` (and `AIPlanGeneratorService`); quality curation and fallbacks for workouts and nutrition.
- **Testing:** Dedicated tests cover exercise matching, template scheduling, performance analytics, personal records, and workout schedule guardrails.
